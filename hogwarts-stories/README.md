# Історії на двох

Бібліотека інтерактивних романтичних історій у форматі сторіс із реалістичними фото.

1. На головному екрані — 5 історій, у кожній своя героїня, характер і зав'язка (каталог: `public/catalog.js`).
2. Обираєш історію й робиш перший крок. **Claude** пише розділ з оповіддю й репліками, а читач у ньому — головний герой («ти»). Довжину розділу Claude обирає сам, від 2 до 10 кадрів, залежно від того, що попросив читач.
3. Модель картинок робить до кожного кадру **реалістичне фото**. За замовчуванням це Seedream (`bytedance-seed/seedream-5.0-pro`) через **OpenRouter**, і всі фото розділу робляться паралельно. Спершу генерується портрет героїні, і він іде зразком у кожне фото, щоб її обличчя не змінювалося.
4. Кадри гортаються лише тапом, без автоперемикання. Після останнього кадру розділу з'являється **«Що робиш далі?»**: пишеш будь-що (або обираєш одну з 3 підказок), і генерується наступна сцена. Кожна історія зберігається окремо, тож до неї можна повернутися.

**Налаштування (⚙️):**
- модель для тексту: **Claude або Grok** (у версії для Pages — перемикач і ключ xAI; на сервері — `TEXT_PROVIDER=grok` і `XAI_API_KEY`);
- ключ і модель фото на OpenRouter;
- **редактор промптів**: промпт сюжету й стиль фото можна переписати вручну або скинути до стандартних. Свої промпти зберігаються в браузері й надсилаються з кожним запитом.

**Межі контенту** (`server/prompts.js`) додаються до будь-якого промпту автоматично й не редагуються: романтика й флірт — так, відвертих сцен і оголення немає, усі персонажі дорослі, жодних романтичних сюжетів між родичами, люди на фото завжди вдягнені.

## Версія для GitHub Pages (без сервера)

Папка `docs/` у корені репозиторію містить ту саму програму без сервера. Claude та OpenRouter викликаються прямо з браузера, а ключі кожен вводить на своєму пристрої (кнопка 🔑). Ключі зберігаються в `localStorage` і надсилаються тільки в Anthropic та OpenRouter.

Адреса: `https://igorprok24.github.io/Communicator/` (Settings → Pages → гілка `claude/harry-potter-interactive-comic-9wtna3`, папка `/docs`).

Після змін у `public/`, `server/` чи `pages/` перезбери: `npm run build:pages`.

## Версія з сервером

Потрібен Node.js 22.9+.

```bash
cd hogwarts-stories
npm install
cp .env.example .env     # встав ANTHROPIC_API_KEY і OPENROUTER_API_KEY
npm start                # http://localhost:3000
```

`npm run demo` запускає демо-режим із заглушками замість тексту й фото, ключі не потрібні. Для публічного хостингу (наприклад, Render, див. `render.yaml`) задай `APP_PASSWORD`, щоб сторонні не витрачали твої кредити.

## Як це влаштовано

```
public/          інтерфейс (index.html, styles.css, app.js, catalog.js)
pages/direct.js  «бекенд» у браузері для GitHub Pages: Claude SDK + OpenRouter, фото в IndexedDB
server/
  index.js       Express: POST /api/chapter, POST /api/image
  story.js       виклик Claude (стрімінг, structured outputs → JSON розділу)
  grok.js        виклик Grok (xAI API, стрімінг, json_schema)
  chapter.js     спільне: помилки й розбір JSON розділу
  prompts.js     системний промпт, межі контенту, JSON-схема, стиль і промпти фото
  images.js      OpenRouter або OpenAI Images → generated/*
  mock.js        демо-режим
scripts/build-pages.mjs  збірка docs/
```

- Сервер не зберігає стан: клієнт щоразу надсилає картку історії й текст попередніх розділів.
- Тексту на фото немає: оповідь і репліки накладаються поверх фото в HTML (репліки — у вигляді повідомлень у месенджері).
- Якщо класифікатор безпеки Claude відхилить запит, серверний fallback (`fallbacks: "default"`) повторює його на резервній моделі. Вимикається через `CLAUDE_FALLBACKS=0`.

Решта налаштувань (модель, стиль фото, паралельність) — у `.env.example`. Модель фото у версії для Pages можна змінити в панелі 🔑.

Папка `claude-artifact/` — стара версія про Гаррі Поттера для claude.ai, вона більше не оновлюється.
