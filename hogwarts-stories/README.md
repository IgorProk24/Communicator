# ⚡ Хроніки Гоґвортсу — інтерактивний комікс-сторіс

Фанфік-комікс про Гаррі Поттера у форматі Instagram-сторіс, сюжет якого пишеш ти.

1. Пишеш, з чого почнеться історія.
2. **Claude** пише сценарій розділу: 5 слайдів з оповіддю, репліками й звуковими ефектами.
3. **OpenAI (gpt-image)** малює кожен кадр.
4. Гортаєш слайди як сторіс. Після 5-го слайда з'являється питання **«Що буде далі?»**: вписуєш будь-який промт (або обираєш одну з 3 підказок), і генеруються наступні 5 слайдів.

## Запуск

Потрібен Node.js 22.9+.

```bash
cd hogwarts-stories
npm install
cp .env.example .env     # встав ANTHROPIC_API_KEY і OPENAI_API_KEY
npm start                # http://localhost:3000
```

Відкрий адресу з телефона в тій самій Wi-Fi мережі (`http://<IP-комп'ютера>:3000`) або в браузері на компʼютері.

**Без ключів:** `npm run demo` запускає демо-режим із заглушками замість сценарію й картинок. Так зручно подивитися інтерфейс.
Якщо задано лише `ANTHROPIC_API_KEY`, сценарій буде справжній, а замість ілюстрацій будуть заглушки.

## Керування

| Дія | Як |
|---|---|
| Наступний слайд | тап у правій частині екрана, `→` |
| Попередній слайд (і попередні розділи) | тап у лівій третині, `←` |
| Пауза | утримувати палець на екрані, кнопка ❚❚ або `Пробіл` |
| На головну | ✕ або `Esc` |

Слайди перегортаються самі. Таймер стартує, тільки коли кадр уже намальований, а тривалість залежить від кількості тексту.
Історія зберігається в `localStorage` браузера, тож її можна продовжити пізніше.

## Як це влаштовано

```
public/          фронтенд без збірки (index.html, styles.css, app.js)
server/
  index.js       Express: POST /api/chapter, POST /api/image, статика
  story.js       виклик Claude (structured outputs → JSON розділу)
  prompts.js     системний промпт, JSON-схема, стиль ілюстрацій
  images.js      OpenAI Images → generated/*.webp
  mock.js        демо-режим
generated/       намальовані кадри (не в git)
```

- Сервер не зберігає стан: клієнт щоразу надсилає текст попередніх розділів, і Claude продовжує сюжет з урахуванням усієї історії.
- Щоб герої виглядали однаково на всіх кадрах, Claude веде «візуальний паспорт» кожного персонажа англійською. Його опис додається до промпту кожного кадру, де цей персонаж є.
- Модель картинок не отримує імен героїв чи назви франшизи, а лише опис зовнішності. Так менше відмов модерації. Тексту на самих малюнках немає: оповідь і репліки накладаються поверх кадру в HTML, тому українська завжди відображається правильно.
- Якщо класифікатор безпеки Claude відхилить запит, вмикається серверний fallback (`fallbacks: "default"`): запит автоматично повторюється на резервній моделі. Вимкнути це можна через `CLAUDE_FALLBACKS=0`.

## Вартість (орієнтовно)

- Сценарій одного розділу на `claude-opus-5-5`: кілька центів.
- Кадри: 5 зображень на розділ. Ціна залежить від `OPENAI_IMAGE_QUALITY` (`low` найдешевший, `medium` за замовчуванням).

Решту налаштувань (модель, якість картинок, паралельність) дивись у `.env.example`.
